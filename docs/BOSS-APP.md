# 사장님 배차 앱

접속: https://k119.vercel.app/boss.html

## 휴대폰 설치

1. 갤럭시의 Chrome에서 위 주소를 엽니다.
2. 사장님이 사용할 기존 관리자 이메일과 비밀번호로 로그인합니다. 병원 담당자 계정은 사용할 수 없습니다.
3. 화면 위 `휴대폰에 설치`를 누르고 설치창에서 확인합니다. 설치창이 없으면 Chrome 오른쪽 위 `⋮` → `홈 화면에 추가` → `설치`를 선택합니다.
4. 홈 화면의 **사장님 배차** 아이콘을 열어 같은 전용 화면이 나오는지 확인합니다. 사장님께는 이 아이콘만 사용하도록 안내합니다.

아이폰에서는 Safari로 주소를 열고 공유 → 홈 화면에 추가를 사용합니다. 실제 휴대폰의 설치 확인은 사용자가 직접 해야 합니다. 기존 `EMS 9090` 기사 앱과 설치 주소/앱 ID가 다릅니다.

## 사장님께 설명할 내용

- 새 예약은 큰 카드로 자동 표시됩니다. 병원·환자·시각·출발지·도착지를 읽습니다.
- 기사 심재용의 71나9090이 운행하면 파란 **9090 배차**를 누릅니다.
- 다른 차가 운행하면 **타차량 배차**를 누릅니다. 다른 기사에게 연락하는 일은 별도로 직접 합니다.
- 확인 화면에서 내용을 다시 읽고 **예, … 확정**을 누릅니다. 잘못 눌렀으면 **아니요, 돌아가기**를 누릅니다.
- 처리 후 초록색 완료 문구가 뜨고 예약 카드가 대기 목록에서 사라집니다.
- 오류가 뜨면 성공한 것으로 판단하지 말고 연결과 최신 예약을 확인합니다.

앱을 열어둔 동안 실시간 구독과 5초 재조회로 예약을 확인합니다. 닫혀 있는 앱에 새 예약 푸시를 보내는 기능은 이번 화면에 추가하지 않았습니다. 인터넷 연결이 필요하며 오프라인 배차는 지원하지 않습니다.

## 접근과 권한

전용 화면일 뿐 권한을 줄인 새 관리자 역할은 아닙니다. 기존 관리자 계정의 권한을 그대로 사용합니다. 가입 승인·정산 등의 메뉴는 전용 화면에서 숨겨 단순화했고, 전체 관리자 화면은 하단 링크로 이동할 수 있습니다. 기존 Supabase RLS와 배차 RPC를 사용하며 비밀키는 추가하지 않았습니다.
